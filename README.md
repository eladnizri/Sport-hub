# חמ״ל ספורט

אפליקציית ספורט אישית שמרכזת במסך אחד תוצאות בזמן אמת, מעקב לגיונרים,
רדאר העברות ומצב יום משחק. ממשק בעברית, RTL מלא, ומותאם קודם כל לנייד.

## מה יש בפנים

| מסך | מה הוא עושה |
| --- | --- |
| **בית** | סיכום היום: כמה משחקים חיים, כמה לגיונרים על המגרש, מה רץ עכשיו ומה הבא בתור |
| **לייב** | לוח תוצאות מלא עם סינון לפי ליגה/סטטוס. הקשה על משחק פותחת סטטיסטיקות ואירועים |
| **לגיונרים** | פיד ממוקד לדקות, שערים, בישולים וציונים של הישראלים באירופה ובליגה |
| **רדאר** | שוק ההעברות בכדורגל וב-NBA — שלב העסקה, מקור ודירוג אמינות |
| **יום משחק** | תצוגה מרוכזת במסך מלא לכל המשחקים שרצים במקביל. נפתח מכפתור הרשת או אוטומטית |

ליגות נתמכות: ליגת העל, הפרמייר ליג, ליגת האלופות, המפעלים האירופיים של
הקבוצות הישראליות, NBA ויורוליג. אפשר לכבות ולהדליק כל אחת מהן בהגדרות.

## הרצה

```bash
npm install
npm run dev      # http://localhost:5173
```

```bash
npm run build    # בנייה לפרודקשן אל dist/
npm run preview  # בדיקת הבנייה
npm run typecheck
```

האפליקציה היא PWA — בנייד אפשר "הוסף למסך הבית" והיא תיפתח במסך מלא.

## חיבור נתונים אמיתיים

מתוך הקופסה האפליקציה רצה על **ספק דמו**: לוח משחקים שמעוגן לשעון האמיתי,
עם דקות שמתקדמות ושערים שנופלים. כל מסך מסמן בתחתיתו אם מה שמוצג הוא
לייב או הדגמה, כדי שלא יהיה רגע שבו מספר דמו נראה כמו תוצאה אמיתית.

כדי לעבור ללייב:

1. `cp .env.example .env`
2. מלא מפתחות:
   - `VITE_API_FOOTBALL_KEY` — [API-Football](https://dashboard.api-football.com)
     מכסה את ליגת העל, הפרמייר ליג, ליגת האלופות והמפעלים האירופיים.
     השכבה החינמית מוגבלת ל-100 קריאות ליום.
   - `VITE_BALLDONTLIE_KEY` — [balldontlie](https://app.balldontlie.io) ל-NBA.
     השכבה החינמית מחזירה לוח משחקים ותוצאות סופיות; **לייב דורש מנוי בתשלום**.
3. הפעל מחדש את שרת הפיתוח. מסך ההגדרות יראה "מחובר" לכל ספק שהוגדר.

ליגות שאין להן ספק מוגדר (יורוליג), או קריאה שנכשלה, נופלות אוטומטית
לספק הדמו — האפליקציה לא נשארת ריקה.

> **אזהרת אבטחה:** כל משתנה שמתחיל ב-`VITE_` נארז לתוך ה-bundle של הדפדפן
> וגלוי לכל מי שפותח את קוד המקור של הדף. לשימוש אישי זה תקין. אם אתה
> מפרסם את האפליקציה לאינטרנט, העבר את הקריאות דרך פרוקסי בצד שרת שמחזיק
> את המפתח, במקום לשלוח אותו מהדפדפן.

### רדאר ההעברות

אין ספק ציבורי אמין לשמועות העברות, ולכן הפיד הזה רץ על מקור עריכתי מקומי
ומסומן כדמו. הוא מוכן לחיבור: מלא את `getTransfers` ב-`src/data/index.ts`
במקור שתבחר (RSS של עיתונאי, API פנימי) והמסך יעבוד כמו שהוא.

## מבנה הקוד

```
src/
  data/
    competitions.ts        הליגות והמפעלים במעקב
    legionnaires.ts        רשימת הלגיונרים — קובץ תצורה לעריכה ידנית
    index.ts               שכבת הנתונים היחידה שהמסכים מדברים איתה
    providers/
      demo.ts              ספק הדמו — לוח מעוגן לשעון עם דקות שמתקדמות
      apiFootball.ts       אדפטר API-Football
      balldontlie.ts       אדפטר NBA
  screens/                 בית, לייב, לגיונרים, רדאר, יום משחק
  components/              כרטיס משחק, טאב בר, גיליון הגדרות, אייקונים
  styles/global.css        טוקנים ומערכת העיצוב
```

המסכים לא יודעים מאיפה מגיעים הנתונים — הם קוראים ל-`getMatches`,
`getLegionnaires` ו-`getTransfers` בלבד. החלפת ספק היא שינוי בקובץ אחד.

## לפני שנשענים על הנתונים

`src/data/legionnaires.ts` הוא נקודת פתיחה, לא מקור אמת: שיוך שחקן למועדון
משתנה בכל חלון העברות. ודא מול מקור עדכני ועדכן את הקובץ. גם פיד ההעברות
בספק הדמו הוא תוכן לדוגמה בלבד.

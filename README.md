# חמ״ל ספורט

אפליקציית ספורט אישית שמרכזת במסך אחד תוצאות בזמן אמת, מעקב לגיונרים,
רדאר העברות ומצב יום משחק. ממשק בעברית, RTL מלא, ומותאם קודם כל לנייד.

## מה יש בפנים

| מסך | מה הוא עושה |
| --- | --- |
| **בית** | סיכום היום: כמה משחקים חיים, כמה לגיונרים על המגרש, מה רץ עכשיו ומה הבא בתור |
| **לייב** | לוח תוצאות מלא עם סינון לפי ליגה/סטטוס. הקשה על משחק פותחת סטטיסטיקות ואירועים |
| **לגיונרים** | פיד ממוקד לדקות, שערים, בישולים וציונים של הישראלים באירופה ובליגה |
| **רדאר** | שוק ההעברות בכדורגל וב-NBA — שלב העסקה, מקור ודירוג אמינות |
| **יום משחק** | תצוגה מרוכזת במסך מלא לכל המשחקים שרצים במקביל. נפתח מכפתור הרשת או אוטומטית |

ליגות נתמכות: ליגת העל, הפרמייר ליג, ליגת האלופות, המפעלים האירופיים של
הקבוצות הישראליות, NBA ויורוליג. אפשר לכבות ולהדליק כל אחת מהן בהגדרות.

## הרצה

```bash
npm install
npm run dev      # http://localhost:5173
```

```bash
npm run build    # בנייה לפרודקשן אל dist/
npm run preview  # בדיקת הבנייה
npm run typecheck
npm run leagues  # שולף את מזהי הליגות מהחשבון שלך (דורש מפתח)
```

האפליקציה היא PWA — בנייד אפשר "הוסף למסך הבית" והיא תיפתח במסך מלא.

## חיבור נתונים אמיתיים — שלב אחר שלב

מתוך הקופסה האפליקציה רצה על **ספק דמו**: לוח משחקים שמעוגן לשעון האמיתי,
עם דקות שמתקדמות ושערים שנופלים. כל מסך מסמן בתחתיתו אם מה שמוצג הוא
לייב או הדגמה, כדי שלא יהיה רגע שבו מספר דמו נראה כמו תוצאה אמיתית.

### שלב 1 — הוצא מפתח לכדורגל (API-Football)

מכסה את ליגת העל, הפרמייר ליג, ליגת האלופות והמפעלים האירופיים.

1. היכנס ל-<https://dashboard.api-football.com> והירשם.
2. **הירשם ישירות באתר של api-football, לא דרך RapidAPI.** שתי הדרכים
   משתמשות בכתובת ובכותרת אימות שונות; הקוד כאן מדבר עם
   `v3.football.api-sports.io` והכותרת `x-apisports-key`, כלומר הגרסה
   הישירה. מפתח RapidAPI לא יעבוד בלי לשנות את האדפטר.
3. אשר את המייל, ובדשבורד היכנס ל-**Profile → API Key** והעתק את המפתח.

התוכנית החינמית מוגבלת ל-100 קריאות ליום. האפליקציה מושכת פעם ב-30 שניות
כשיש משחק חי — כלומר בערך 120 קריאות בשעה. אם אתה על התוכנית החינמית,
כבה "רענון אוטומטי" בהגדרות ורענן ידנית, או שהמכסה תיגמר תוך פחות משעה.

### שלב 2 — הוצא מפתח ל-NBA (balldontlie)

1. היכנס ל-<https://app.balldontlie.io> והירשם.
2. העתק את המפתח מהדשבורד.

> השכבה החינמית מחזירה לוח משחקים ותוצאות סופיות בלבד. **תוצאות חיות
> ושעון משחק דורשים מנוי בתשלום.** בלי מנוי, משחקי NBA יופיעו כמתוכננים
> עד שהתוצאה הסופית מתעדכנת — זו מגבלה של הספק, לא באג.

### שלב 3 — הכנס את המפתחות לקובץ .env

```bash
cp .env.example .env
```

ערוך את `.env`:

```
VITE_API_FOOTBALL_KEY=המפתח_שלך_מ_api_football
VITE_BALLDONTLIE_KEY=המפתח_שלך_מ_balldontlie
```

אפשר למלא רק אחד מהם. ליגה שאין לה ספק מוגדר נופלת לספק הדמו.

### שלב 4 — אמת את מזהי הליגות

מזהי הליגות אצל הספק אינם קבועים בין תוכניות, והערכים שבקוד הם ברירת מחדל
שלא אומתה מול חשבון אמיתי. הרץ:

```bash
npm run leagues
```

הסקריפט מדפיס את המזהים האמיתיים מהחשבון שלך. העתק אותם אל
`src/data/competitions.ts`, לשדה `providerIds`. שים לב ש"מפעלים אירופיים"
מקבל **שני** מזהים — ליגה אירופית וקונפרנס ליג — כי הקבוצות הישראליות
מופיעות בעיקר בקונפרנס.

### שלב 5 — הפעל מחדש ובדוק

```bash
npm run dev
```

Vite קורא את `.env` רק בעליית השרת, ולכן חובה להפעיל מחדש. פתח את
**הגדרות** (גלגל השיניים במסך הבית) — תחת "מקורות נתונים" כל ספק שהוגדר
יסומן **"מחובר"**. בתחתית כל מסך תראה "נתונים חיים" במקום "נתוני הדגמה".

אם עדיין כתוב "נתוני הדגמה" אחרי שהמפתח מוגדר: הקריאה נכשלה. פתח את
קונסולת הדפדפן ובדוק את שגיאת הרשת — בדרך כלל מפתח שגוי, מכסה יומית
שנגמרה, או מזהה ליגה לא נכון.

> **אזהרת אבטחה:** כל משתנה שמתחיל ב-`VITE_` נארז לתוך ה-bundle של הדפדפן
> וגלוי לכל מי שפותח את קוד המקור של הדף. לשימוש אישי זה תקין. אם אתה
> מפרסם את האפליקציה לאינטרנט, העבר את הקריאות דרך פרוקסי בצד שרת שמחזיק
> את המפתח, במקום לשלוח אותו מהדפדפן. `.env` כבר ב-`.gitignore` — אל
> תסיר אותו משם.

### רדאר ההעברות

אין ספק ציבורי אמין לשמועות העברות, ולכן הפיד הזה רץ על מקור עריכתי מקומי
ומסומן כדמו. הוא מוכן לחיבור: מלא את `getTransfers` ב-`src/data/index.ts`
במקור שתבחר (RSS של עיתונאי, API פנימי) והמסך יעבוד כמו שהוא.

## מבנה הקוד

```
src/
  data/
    competitions.ts        הליגות והמפעלים במעקב
    legionnaires.ts        רשימת הלגיונרים — קובץ תצורה לעריכה ידנית
    index.ts               שכבת הנתונים היחידה שהמסכים מדברים איתה
    providers/
      demo.ts              ספק הדמו — לוח מעוגן לשעון עם דקות שמתקדמות
      apiFootball.ts       אדפטר API-Football
      balldontlie.ts       אדפטר NBA
  screens/                 בית, לייב, לגיונרים, רדאר, יום משחק
  components/              כרטיס משחק, טאב בר, גיליון הגדרות, אייקונים
  styles/global.css        טוקנים ומערכת העיצוב
scripts/
  find-leagues.mjs         שולף מזהי ליגות אמיתיים מ-API-Football
```

המסכים לא יודעים מאיפה מגיעים הנתונים — הם קוראים ל-`getMatches`,
`getLegionnaires` ו-`getTransfers` בלבד. החלפת ספק היא שינוי בקובץ אחד.

## לפני שנשענים על הנתונים

`src/data/legionnaires.ts` הוא נקודת פתיחה, לא מקור אמת: שיוך שחקן למועדון
משתנה בכל חלון העברות. ודא מול מקור עדכני ועדכן את הקובץ. גם פיד ההעברות
בספק הדמו הוא תוכן לדוגמה בלבד.

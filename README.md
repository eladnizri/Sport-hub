# חמ״ל ספורט

אפליקציית ספורט אישית שנועדה להיות מקור אחד לכל מה שמעניין אותך —
ולא עוד אפליקציית תוצאות. ממשק בעברית, RTL מלא, מותאם קודם כל לנייד.

העיקרון: **הקשר במקום מספרים**. כל מסך עונה על שאלה, בשורה אחת או שתיים,
ואז נגמר.

## מה יש בפנים

| מסך | השאלה שהוא עונה עליה |
| --- | --- |
| **בית** | מה קורה עכשיו — משחקים חיים, לגיונרים על המגרש, מה הבא בתור |
| **לייב** | לוח משחקים עם סינון. הקשה פותחת סטטיסטיקות, אירועים, וסיכום שלוש שורות למשחק שהסתיים |
| **טבלה** | איפה הקבוצה תהיה אם המחזור ייגמר ככה — טבלה שזזה תוך כדי המשחקים |
| **לגיונרים** | האם הוא בדרך למעלה או למטה — מגמת דקות, מעמד בהרכב, המשחק הבא |
| **רדאר** | שוק ההעברות: שלב העסקה, מקור ודירוג אמינות |
| **יום משחק** | מסך מלא לכל המשחקים שרצים במקביל |

### ארבעת הדברים שהופכים את זה ליותר מתוצאות

**טבלה חיה עם תרחישים.** הטבלה שהספק מחזיר משקפת רק משחקים שהסתיימו.
`src/lib/liveTable.ts` מחיל עליה את המשחקים שרצים כרגע ומחזיר גם את
המיקום המוקרן וגם את זה שממנו יצאנו — כך שהמסך מראה תנועה, לא שורה.
מעליה נבנים משפטי תרחיש ("ניצחון והפועל ב״ש עוברת למקום שני"), שמחושבים
על ידי מיון הטבלה מחדש בהנחת תוצאה אחרת — לא בניחוש.

**תיק לגיונר.** `src/lib/dossier.ts` לא שואל "כמה דקות שיחק אתמול" אלא
משווה שני משחקים אחרונים לשלושה שלפניהם, ומחזיר כיוון מגמה, רצף הרכבים
וגרף דקות זעיר. ההיסטוריה נצברת בין הרצות ולכן משתפרת עם הזמן.

**סיכום שלוש שורות.** מה הכריע, מי בלט, מה המשמעות לטבלה. נכתב בצד השרת
על ידי Llama 3.3 70B דרך Groq ונאפה לקאש, כך שכל משחק מסוכם פעם אחת.
כשאין מפתח או שהקריאה נכשלה, `src/lib/narrative.ts` בונה סיכום מהנתונים
לפי כללים — והמסך מסמן במפורש מי כתב.

**ניהול לגיונרים.** הרשימה נבנית משלוש שכבות: בסיס בקוד, זיהוי אוטומטי
בצד השרת, ועריכות שלך שנשמרות במכשיר ומנצחות תמיד.

ליגות נתמכות: ליגת העל, הפרמייר ליג, ליגת האלופות, הליגה האירופית וליגת
הקונפרנס. ה-NBA קיים כהקשר ללגיונר בלבד (אבדיה) ולא כליגה שגולשים בה —
הדגל `legionnaireOnly` ב-`src/data/competitions.ts` שולט בזה.

## איך הנתונים מגיעים

השכבה החינמית של api-football נותנת **100 קריאות ביום**, וזה לא מספיק
לטבלאות, כושר וסטטיסטיקות שחקנים בזמן אמת. לכן:

```
GitHub Action מתוזמן ──> api-football ──> סיכומים ב-Groq
                                 │
                                 ▼
                   public/data/snapshot.json  ──>  הדפדפן
```

1. **הקאש הסטטי** הוא המקור הראשי. אין מפתח API בדפדפן, הטעינה מיידית,
   וה-Action נשאר בתוך המכסה (`CALL_BUDGET` לכל הרצה).
2. **רענון חי** נשרף רק כשיש על המסך משחק *שלך* — קבוצה ישראלית, מועדון
   של לגיונר, או קבוצה שסימנת. ההיגיון ב-`src/lib/myMatches.ts`, והמתג
   בהגדרות (`לייב למשחקים שלי`) מכבה אותו לגמרי.
3. **ספק דמו** כשאין קאש ואין מפתח, כדי שאפשר יהיה לפתח בלי חשבון.

בכל מסך יש שורת מקור שאומרת אם מה שרואים חי, מהקאש או הדגמה. שום מספר
לא מתחזה למשהו שהוא לא.

### חיסכון בקריאות

הסקריפט (`scripts/build-cache.mjs`) בנוי כדי לא לשלם פעמיים:

- לוח משחקים נמשך בקריאה אחת לכל תאריך, בלי סינון ליגה — הסינון מקומי.
- טבלאות נמשכות רק אם הסתיים משחק מאז ההרצה הקודמת, או שעברו 12 שעות.
- אירועים וסטטיסטיקות שחקנים נמשכים רק למשחקים שמעניינים אותך, ורק פעם
  אחת לכל משחק — ההיסטוריה נצברת ב-`actions/cache` בין הרצות.
- סיכום נכתב פעם אחת לכל משחק ונשמר בקאש.

בשגרה זה יוצא כ-25 קריאות ביום, ומשאיר מרווח נוח לרענון חי.

## הקמה

### 1. מפתחות

| סוד ב-GitHub | מאיפה | חובה? |
| --- | --- | --- |
| `API_FOOTBALL_KEY` | [dashboard.api-football.com](https://dashboard.api-football.com) | כן |
| `GROQ_API_KEY` | [console.groq.com/keys](https://console.groq.com/keys) | לא — בלעדיו הסיכומים תבניתיים |

הוסף אותם ב-**Settings → Secrets and variables → Actions**.

### 2. מזהי ליגות

מזהי הליגות ב-`src/data/competitions.ts` ובראש `scripts/build-cache.mjs`
צריכים להיות זהים. אם ליגה חוזרת ריקה, שלוף את המזהים מהחשבון שלך:

```bash
API_FOOTBALL_KEY=xxx npm run leagues
```

### 3. Pages

הפעל GitHub Pages במצב **GitHub Actions**. שני ה-workflows מפרסמים אליו:
`deploy.yml` בכל דחיפה, ו-`refresh-data.yml` לפי לוח הזמנים.

## הרצה מקומית

```bash
npm install
npm run dev        # http://localhost:5173 — רץ על נתוני דמו
npm run build
npm run preview
npm run typecheck

API_FOOTBALL_KEY=xxx GROQ_API_KEY=yyy npm run cache   # בניית הקאש מקומית
npm run leagues                                        # שליפת מזהי ליגות
```

בלי מפתחות האפליקציה רצה על ספק הדמו: לוח משחקים שזז עם השעון, טבלאות
יציבות, והיסטוריית לגיונרים עם מגמות אמיתיות. כל המסכים עובדים.

```
src/

    providers/
      cache.ts      קריאת snapshot.json

```

## מה עוד אפשר להוסיף

- **שורת "למה זה חשוב" לפני משחק** — הטבלה החיה כבר יודעת מה על הכף.
- **דייג׳סט בוקר** בחמש שורות, כ-Action נפרד ששולח התראה.
- **מד "כדאי לראות"** — ציון למשחק לפי צמידות, חשיבות ולגיונר על המגרש.
- **פיד העברות אמיתי** — הרדאר עדיין רץ על תוכן דמו, ומסומן ככזה.
